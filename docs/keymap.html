Default レイヤーの特殊キー

Esc / Tab単押しで Esc・Tab、長押し中はレイヤー 1・2 が有効（&lt）。レイヤー 1 は Lock キーで固定もできる
Enter / `単押しで Enter・`、長押しで ⌘・Shift（mtq、balanced / 200ms。quick-tap-ms により連打も効く）
Space単押しで Space、長押しで Option（mt_spc、tap-preferred / 200ms。タイプ直後 150ms は必ず Space を出す）
Option（左右 2 箇所）左小指の最下段と、Space の長押し。⌘⌥ は ⌘ が右親指のため、左の Option を使う
Ctrl（左右 2 箇所）左小指の最下段と、右小指中段の = 長押し。Ctrl+P は左、Ctrl+E Ctrl+Z は右を使う
Shift（左右 2 箇所）左小指外側の下段と、右小指最下段の ` 長押し。Q E Z は右 Shift、P H B は左 Shift を使う
BS・/ （右小指）単独キーのため、押しっぱなしでキーリピートが効く
\単押しで \、長押しでレイヤー 3（F キー / Bluetooth）。左手を使わずに入れる。> はレイヤー 2 の左手中段内側へ移動
右クリック単押しで右クリック、長押し（150 ms）でレイヤー 4（スクロール）。トラックパッドが縦横スクロールに変わる
, . - ;大西配列では文字段の内側（人差し指）に配置される。[ ] ' はレイヤー 1 の右手内側列へ移動

レイヤー1固定

右手はテンキー相当の数字配列。左手は Excel 操作に割り当て、左親指の Shift と、右親指の ⌘（単押しは .）を方向キーと組み合わせる （⌘+方向 でデータ端へジャンプ、⇧+方向 で選択拡張、⌘⇧+方向 で端まで選択）。 Shift と ⌘ を左右の親指に分けてあるのは、同じ親指では 2 つのキーを同時に押せないため。 長時間の表操作では、Esc を長押ししたまま右小指最下段の Lock（&tog 1）を押すとレイヤー 1 が固定され、両手が自由になる。もう一度 Lock を押すと解除。 左手のキーは小指列から人差し指列（ホームポジション）に並べてあるため、Lock で固定してから使う。Esc を長押ししている間は左小指が塞がり、小指列のキーは押せない。 固定中は左小指が空くため、Esc の位置にセル編集キャンセル用の Esc を置いてある（固定中のみ有効）。文字を入力するときは Lock を解除する。 エンコーダは Default レイヤーの設定を引き継ぐ。

レイヤー2固定
エンコーダ（左）回転で音量 下 / 上 ― このレイヤーだけ横スクロールから切り替わる
エンコーダ（右）回転で縦スクロール（下 / 上）

左手中段が方向キー、その上段が行頭・行末・文書先頭・文書末尾。左親指の Shift と右親指の ⌥ を併用して ⇧+方向（選択拡張）、⌥+方向（単語単位の移動）、⇧⌥+方向（単語単位の選択）、 ⇧+⌘←（行頭まで選択）を作る。左手下段には Shift が必要な記号のうち、他のレイヤーに無い 5 つ（{ } " : <）を置き、中段の内側に > を置く。 右手は内側 4 列が記号、小指 2 列が Magnet のウィンドウ分割（左列が 1/3、右列が 2/3、行が 左・中央・右）。デスクトップの左右切替は左右の親指に分けてある。Shift と ⌥ を同じ親指に置くと ⇧⌥+方向 が押せなくなるため。右小指下段は Mission Control と Lock（&tog 2）。左手のキーは小指列から人差し指列（ホームポジション）に並べてあるため、Lock で固定してから使う。Tab を長押ししている間は左小指が塞がり、小指列のキーは押せない。長い選択やログの読み飛ばしでは、Tab を長押ししたまま Lock を押すとレイヤー 2 が固定され、左小指を押さえ続けずに済む。もう一度 Lock で解除。固定中は Esc の位置で Esc が出る（&kp ESC）。 ⌘C ⌘V ⌘R は Default レイヤーの ⌘（Enter 長押し）と文字キーで押せるため、このレイヤーからは外した。

レイヤー 4右クリック（左親指）長押しで有効 — スクロール

押している間、トラックパッドの動きが縦横スクロールに変わる（zip_xy_to_scroll_mapper、感度 1/16）。 キーはすべて Default レイヤーを透過するため、⌘（Enter 長押し）を足したズーム、 Shift（` 長押し）を足した横スクロールもそのまま使える。 左親指で押しながら、右手でトラックパッドを操作する。

動作の設定値

スクロール量150（既定値と同じ）
スクロール加速なし（最大速度まで 0ms、加速指数 0）
Mod-Tap直前 150ms 以内に打鍵があれば単押し扱い
Enter / ⌘、` / ⇧balanced、判定 200ms、quick-tap 200ms（mtq）
Space / Optiontap-preferred、判定 200ms、prior-idle 150ms
エンコーダzmk_encoder モジュール。1 回転 1 イベントでスクロールを完了
中央側右手（R）。ZMK Studio 有効
周辺側左手（L）
ポインタトラックパッド版 / トラックボール版の 2 種
